## 意图与缘由

v1 的三种动画全是喜庆温馨系，`error`/`warning` 这类坏消息日志没有任何彩蛋。本次补上情绪谱的另一半：
**下雨**接「翻车了」「凉了」这类发蔫时刻，**打雷**接「雷人」这类震惊时刻，并把触发词表从
「自然现象」扩到「情绪吐槽」。目标：彩蛋覆盖日志情绪全谱——庆祝、温馨、发蔫、震惊。

## 目标

1. `EffectType` 联合类型扩为 `'fireworks' | 'confetti' | 'snow' | 'rain' | 'lightning'`
2. `DEFAULT_EFFECT_TRIGGERS` 扩表（见「已定决策」），键插入序 = 命中优先级，坏消息压过好消息
3. 两台新粒子形态：rain（雪引擎换参数）与 lightning（锯齿折线 + 全屏闪白，全新形态）
4. mockup 补 rain / lightning 两节视觉基准（形态纪律照 v1：参数可微调，形态走样不行）
5. README.md / README.zh-CN.md 词表更新 + 新动画说明；`test/test.html` 演示区补两个按钮
6. 回归测试续 R35 起（词表、优先级首中、两引擎封顶、新词全链路、production/reduced-motion 对新词同样 no-op）

## 非目标

- **不加音频**（雷声）——纯视觉，日志工具不发声
- 不改挂钩机制、防轰炸（单飞 + 播完 2s 冷却）、匹配语义（子串、键 ≥2 字、英文大小写敏感）——新词只进词表，新动画只进 `effects-render`
- 不做正则/分词/i18n 匹配
- 不为业务字面碰撞做运行时白名单或警告（用户已裁定：留着，冷却兜底）
- 不做「打雷带雨」联动（一条日志只播一个动画，v1 语义不变）

## 反目标（做了即失败）

- 动画层干扰页面操作（overlay `pointer-events:none`、播完即移除的纪律必须保持）
- 默认词表收「完了 / 没了 / 裂开 / 崩了 / 炸了」这类日志口头禅（"跑完了""执行完了"会天天误触发）
- 新形态与 mockup 基准走样

## 约束（继承 v1 全部全局约束）

- 零依赖；`src/` 模块顶层零 DOM 访问
- `NODE_ENV=production` 与 `prefers-reduced-motion: reduce` 全部 no-op
- 时长封顶：rain ≤ 6s（目标 4-5s 收）、lightning ≤ 3s（目标 2s 内收）
- 全局单飞 + 播完起算 2s 冷却：跨动画种类也互斥（一条日志只播一个，连续触发只播一次）
- `src/` 内相对导入带 `.ts` 后缀（Ruling 6 既定）；R 编号自 R35 续
- 新测试进 `package.json` 的 `test:unit:offline` 显式清单（沿用 `test/effects.test.ts` 或按需新文件并入清单）

## 用户已定的决策

1. **吐槽词进表**：「翻车了」「凉了」这类吐槽也触发下雨（用户原话："这种吐槽也能触发下雨就更好了"）
2. **碰撞词留着**：雪花、凉了、翻车了等与业务字面撞车的词保留，靠单飞 + 冷却兜底（用户裁定"留着"）
3. 词表两家族并存：自然现象 + 情绪吐槽
4. 坏消息优先："庆祝上线翻车了"应下雨而非撒花（键序即优先级。builder 核对修正：原示例误写"劈雷"，翻车了归 rain，以词表为准）

## 控制器裁决（builder 可复核，用户可否决）

1. **效果英文名**：`'rain'`、`'lightning'`。打雷的视觉是闪电，取形态名词（与 fireworks/confetti/snow 同族）；不叫 thunder（那是声音，我们只画不响）
2. **最终词表**（插入序 = 命中优先级，整表顺序 lightning → rain → snow → fireworks → confetti）：
   - lightning：打雷、雷人
   - rain：下雨、暴雨、翻车了、凉了、寄了、芭比Q了
   - snow：下雪、雪花、初雪（雪花按用户裁定保留；初雪为控制器补的温馨词，零业务碰撞）
   - fireworks：烟花
   - confetti：撒花、庆祝、好耶、恭喜（恭喜为复查发现的最大缺口，日志道贺第一高频词）
3. **拒收词记档防回潮**：完了（跑完了/执行完了 口头禅）、没了、裂开（钢板裂开，IoT 字面义）、崩了（雪崩了）、炸了（"内存炸了"语义双极）、雷（单字不收）、裸"翻车"（物流事故叙述，收"翻车了"代替）
4. 撒花保留（"撒花生/撒花瓣"碰撞低频，随碰撞词裁定一并留着）
5. **lightning 形态**：一道锯齿折线自屏幕上方劈至随机落点（中点位移法生成折线），全屏白闪 2-3 帧，轻微余晖渐隐，2s 内收尾；单次一击（不做多连闪）
6. **rain 形态**：细密灰蓝斜线快落（在雪引擎参数组上改：速度约 4 倍、线更细、透明度更低、固定偏斜角、去摆动去尾迹），4-5s 收尾；底部不加水花（少即是多）
7. mockup 新建 `2026-11-12-rain-lightning-mockup.html`（v1 mockup 归档只读，不动），含 rain / lightning 两节，作为本设计的视觉基准
8. **留作未来（本设计不含）**：爱心、红包雨、流星、鞭炮（上一轮候选，用户未取）
